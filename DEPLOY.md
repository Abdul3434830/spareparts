# Production Deployment Guide: CARS SPARE PARTS

> **BRAND**: CARS SPARE PARTS  
> **TAGLINE**: THE RIGHT PART. THE RIGHT FIT.  
> **SUBHEADING**: Genuine, OEM and performance parts for your car.

This guide provides step-by-step instructions to deploy the complete **CARS SPARE PARTS** platform to **Vercel** with a **Neon Serverless Postgres** database and **Vercel Blob** storage.

---

## 1. Prerequisites Checklist

Before beginning deployment, ensure you have:
- A [Vercel](https://vercel.com) account (Hobby or Pro)
- A [Neon](https://neon.tech) account (Free serverless Postgres) or provision Neon directly inside Vercel Storage
- A GitHub repository containing the committed project code
- A WhatsApp business number for Pakistani customer order notifications and chassis fitment verifications

---

## 2. Setting Up the Database (Neon Postgres)

1. Log in to [Neon.tech](https://neon.tech) and create a new project:
   - **Project Name**: `care-spare-parts-prod`
   - **Region**: Choose closest to target audience (e.g., `Singapore` or `Frankfurt`)
2. Neon will provide two connection strings in your dashboard:
   - **Pooled connection string** (ends with `-pooler.postgres.neon.tech`): Use as `DATABASE_URL`
   - **Direct connection string** (ends with `postgres.neon.tech`): Use as `DIRECT_URL` (for running Prisma migrations)
3. Ensure SSL is enabled (`?sslmode=require`).

---

## 3. Creating Vercel Blob Storage

1. Open your project dashboard in [Vercel](https://vercel.com).
2. Go to the **Storage** tab.
3. Click **Create Database** -> select **Blob**.
4. Name the store: `care-spare-parts-media`.
5. Click **Create Store**. Vercel will automatically generate the `BLOB_READ_WRITE_TOKEN`.

---

## 4. Environment Variables Reference

Configure the following environment variables in your Vercel Project Settings under **Settings > Environment Variables**:

| Variable Name | Environment | Description / Example |
|---|---|---|
| `DATABASE_URL` | Production, Preview | Pooled Postgres connection URL with `?sslmode=require` |
| `DIRECT_URL` | Production, Preview | Direct unpooled connection URL (used for migrations) |
| `AUTH_SECRET` | Production, Preview | 32-byte cryptographically secure random string (generate with `openssl rand -base64 32`) |
| `NEXTAUTH_URL` | Production, Preview | Production URL, e.g. `https://carsspareparts.com` or `https://<project>.vercel.app` |
| `BLOB_READ_WRITE_TOKEN` | Production, Preview | Token generated by Vercel Blob store |
| `NEXT_PUBLIC_WHATSAPP_NUMBER` | Production, Preview | International WhatsApp format without `+` (e.g., `923001234567`) |
| `ADMIN_EMAIL` | Production | Initial seeded admin email, e.g. `admin@carsspareparts.com` |
| `ADMIN_PASSWORD` | Production | Secure initial admin password |

---

## 5. Applying Database Migrations & Initial Seed

Once your environment variables are configured in Vercel:

### Option A: From Local Terminal (Recommended)

Run migrations directly against your production Neon DB from your local machine:

```bash
# 1. Export your Neon connection string in your local terminal
export DATABASE_URL="postgresql://user:password@ep-xyz-pooler.neon.tech/neondb?sslmode=require"
export DIRECT_URL="postgresql://user:password@ep-xyz.neon.tech/neondb?sslmode=require"

# 2. Push schema to Neon
npx prisma db push

# 3. Seed the 12 primary categories and initial administrator account
npm run prisma:seed
```

### Option B: Via Vercel Build Command

In your Vercel Project Settings under **Build & Development Settings**, you can customize the Build Command:

```bash
prisma generate && prisma db push && next build
```

## 6. Verifying the Deployment

1. **Homepage (`/`)**:
   - Verify Montserrat headers and Inter body typography.
   - Test cascading Vehicle Fitment Selector (`Make > Model > Year > Engine`).
   - Check that trust badges, categories grid, and hard-to-find parts sourcing banner are visible.
2. **Shop Catalog (`/shop`, `/shop/[category]`)**:
   - Filter by classification (Genuine, OEM, Aftermarket).
   - Test "Only Show Parts That Fit" toggle with an active vehicle selected in My Garage.
3. **Cart & Multi-Step Checkout (`/cart`, `/checkout`)**:
   - Add a product to the cart.
   - Verify shipping fee calculator (Free above PKR 15,000, flat PKR 450 otherwise).
   - Place a test Cash on Delivery (COD) or Direct Bank Transfer order.
   - Verify redirection to `/checkout/success` with generated order number (`CSP-YYYYMMDD-XXXX`).
4. **Admin Dashboard (`/admin`)**:
   - Log in at `/login` using your configured `ADMIN_EMAIL` and `ADMIN_PASSWORD`.
   - Access `/admin/products/new` to upload multi-image parts with client-side WebP compression.
   - Verify orders queue at `/admin/orders` to assign courier tracking numbers and update statuses.
5. **SEO & Static Routes**:
   - Verify `https://your-domain.com/sitemap.xml` generates dynamically.
   - Verify `https://your-domain.com/robots.txt` disallows `/admin/`, `/account/`, and `/api/`.

---

## 7. Connecting Custom Domain

1. Go to **Settings > Domains** in Vercel.
2. Add your custom domain (e.g., `carsspareparts.com` and `www.carsspareparts.com`).
3. Update your DNS registrar with the CNAME and A records provided by Vercel.
4. SSL certificates are provisioned and renewed automatically via Let's Encrypt.

---

## 8. Support & Emergency Operations

- **Admin Account Recovery**: Password can be reset using `bcrypt` in `prisma/seed.ts` and re-running `npm run prisma:seed`.
- **Database Backups**: Neon Postgres provides instant Point-In-Time Restore (PITR) directly in the Neon dashboard.
